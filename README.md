# Fivebar downloads

Installers for **Fivebar**: takeoff, measurement and markup for construction drawings.

Get the newest version from [Releases](https://github.com/tee-93/fivebar-downloads/releases/latest):

- **Fivebar-Setup-x64.exe** for a normal Windows PC
- **Fivebar-Setup-arm64.exe** for an ARM laptop

Installed copies keep themselves up to date from here.

You need an account to sign in. Ask whoever invited you.
